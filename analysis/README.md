# Analysis — the numbers behind the findings

Everything that produced the figures in [The 61% Problem](../paper/findings-summary.html)
and [LIMITATIONS.md](../LIMITATIONS.md), released so the results can be checked rather
than taken on trust.

**No review text is in this directory.** Every record refers to a review by `review_id`,
an identifier generated by this project. The corpus itself is not redistributed (see the
root README); anyone who re-collects it with the pipeline can join on `review_id` and
re-derive every number here.

## What is where

| Directory | Contents |
|---|---|
| `gold/` | **365 human judgements**, made blind — the annotator never saw a model's answer before committing. `adjudications.jsonl` is the 126-item disagreement-enriched pass; `adjudications_urdu.jsonl` is the 239-item length-matched pass across four language forms. Each record carries the human label and the model predictions it was later compared against. |
| `model_labels/` | Model output on the 500-item diagnostic: intent, secondary intent, refund flag, language, severity, confidence and rationale, per review. Two frontier models labelled every item; the third labelled a handful before being dropped. |
| `authored/` | The 20 complaints written by hand in four language forms — Urdu script, Roman Urdu, code-switched, English — that produced the 95% figure, with the pilot results on them and the change log from transferring them out of the authoring workbook. This is the project's own writing and is fully redistributable. |
| `scripts/` | The Python that produced every reported number: sampling, the two labelling runs, the starved-intent hunt and top-up, the Urdu pass, the decomposition of disagreements, and the power analysis. |
| `reports/` | The text output of those scripts as they ran — the figures as first computed, before any rounding for prose. |

## Reproducing

The scripts were written against paths under `spike/phase3_diag/`, which held the private
working copy of the corpus. To run them, re-collect the corpus with `src/collect/` and
`src/prep/`, place the cleaned file where each script expects it, and point the gold and
model-label paths at the copies in this directory. The scoring logic itself has since been
extracted into `src/adjudicate/`, which is the maintained version; `scripts/adjudicate.py`
is the earlier standalone form kept because it is what the reported numbers came from.

One report is withheld: `decomposition.txt` quotes individual reviews to illustrate each
disagreement class and cannot be released without the text.

## What these files can and cannot support

The judgements come from one annotator, who also authored the taxonomy. Agreement with
those labels is therefore an upper bound on what any independent reader would reach.
Cell sizes are small — the 30.8% joint-error figure rests on 26 controls — and the
per-language comparison could detect a gap of roughly 25 points or more, not a smaller one.
[LIMITATIONS.md](../LIMITATIONS.md) states each of these with its interval.
